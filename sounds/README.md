# Instrument samples

These MP3 samples are from the **FluidR3 GM** SoundFont by Frank Wen, as rendered by
[midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts), and are used under the
[Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/) license.

A sample every three semitones is kept per instrument; the app pitch-shifts the nearest one
to each note it plays.
